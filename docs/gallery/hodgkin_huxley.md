# The action potential

*Neuroscience.* Sodium and potassium channels in the membrane, and the Hodgkin-Huxley model's spikes, conductances, and firing threshold.

![The action potential](../images/gallery-hodgkin_huxley.svg)

**What it shows of FigWorks.** A membrane patch in VecView whose ion colours return in every trace.

**Requires** VecView and TeX.

```bash
python examples/hodgkin_huxley.py
```
