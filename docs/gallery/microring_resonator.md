# A microring resonator

*Photonics.* A ring coupled to a bus waveguide, its comb of resonances, and how the coupling regime shapes each dip.

![A microring resonator](../images/gallery-microring_resonator.svg)

**What it shows of FigWorks.** A VecView chip built from extruded outlines, with colours that carry from the device into the spectra.

**Requires** VecView and TeX.

```bash
python examples/microring_resonator.py
```
